# NOT Gate Using BC547

## Overview

This project demonstrates a NOT gate built using a BC547 NPN transistor.

A NOT gate inverts the input signal.

---

## Components

* BC547 Transistor
* LED
* Push Button
* Resistors
* Breadboard
* 9V Battery

---

## Truth Table

| Input | Output |
| ----- | ------ |
| 0     | 1      |
| 1     | 0      |

---

## How It Works

When the input is LOW, the transistor remains OFF and the LED turns ON.

When the input is HIGH, the transistor turns ON and the LED turns OFF.

This produces the opposite of the input, which is the behavior of a NOT gate.
