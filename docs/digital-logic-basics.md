# Digital Logic Basics

## Introduction

Digital electronics is based on binary logic. Instead of working with a continuous range of voltages, digital circuits operate using two states:

| Logic Level | Voltage |
| ----------- | ------- |
| 0 (LOW)     | 0V      |
| 1 (HIGH)    | 9V      |

These two states represent binary digits,  also known as bits.

---

## What is a Logic Gate?

A logic gate is an electronic circuit that performs a logical operation on one or more inputs and produces a single output.

Logic gates are the building blocks of digital systems such as calculators, computers, and microcontrollers.

---

## Truth Tables

A truth table shows all possible input combinations and their corresponding outputs.

Example: NOT Gate

| Input | Output |
| ----- | ------ |
| 0     | 1      |
| 1     | 0      |

---

## Basic Logic Gates

### NOT Gate

Inverts the input.

### AND Gate

Output is HIGH only when all inputs are HIGH.

### OR Gate

Output is HIGH when at least one input is HIGH.

### NAND Gate

Inverse of the AND gate.

### NOR Gate

Inverse of the OR gate.

### XOR Gate

Output is HIGH when the inputs are different.

---

## Boolean Algebra

Boolean algebra is the mathematical system used to describe logic circuits.

Examples:

AND: A · B

OR: A + B

NOT: A'

---

## Why Logic Gates Matter

Logic gates can be combined to create:

* Adders
* Registers
* Counters
* Memory circuits
* Arithmetic Logic Units (ALUs)
* Central Processing Units (CPUs)

Every modern computer is ultimately built from combinations of logic gates.
