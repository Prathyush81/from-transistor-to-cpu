# Glossary

## ALU

Arithmetic Logic Unit. A circuit that performs arithmetic and logical operations.

## Base

The control terminal of a transistor.

## Binary

A number system that uses only two digits: 0 and 1.

## Bit

A single binary digit.

## Boolean Algebra

A mathematical system used to describe logical operations .

## Collector

The transistor terminal through which current enters.

## Cutoff

The state in which a transistor is OFF.

## Digital Logic

Electronic circuits that operate using discrete HIGH and LOW states.

## Emitter

The transistor terminal through which current leaves.

## Gate

A circuit that performs a logical operation.

## HIGH

A logic level representing 1.

## LOW

A logic level representing 0.

## Logic Gate

An electronic circuit that processes one or more inputs to produce a logical output.

## NAND Gate

A NOT-AND gate.

## NOR Gate

A NOT-OR gate.

## NPN Transistor

A transistor type commonly used for switching and amplification.

## Saturation

The state in which a transistor is fully ON.

## Truth Table

A table showing all possible input combinations and their outputs.

## XOR Gate

A gate that outputs HIGH when inputs are different.
